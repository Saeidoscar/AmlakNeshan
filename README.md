# خانه‌نما

نمونه‌ی اولیه‌ی فارسی و راست‌چین برای جست‌وجوی ملک در ایران. رابط کاربری با HTML/CSS/JavaScript ساده پیاده‌سازی شده و به سرویس یا وابستگی اجرایی نیاز ندارد.

## اجرا

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

سپس `http://localhost:4173` را باز کنید.

## قابلیت‌های نسخه‌ی نمایشی

- تجربه‌ی جست‌وجوی فروش و اجاره در تهران
- کارت‌های ملک با قیمت/ودیعه، متراژ، تعداد اتاق و سال ساخت
- فیلتر نوع ملک، بازه‌ی قیمت، تعداد اتاق و پارکینگ؛ مرتب‌سازی نتایج
- فهرست پیشنهادهای محله هنگام جست‌وجو
- نقشه‌ی شماتیک تعاملی با نشانگرهای متصل به نتایج و کنترل بزرگنمایی
- ذخیره‌ی علاقه‌مندی‌ها در مرورگر، صفحه‌ی جزئیات و فرم پیش‌نویس آگهی
- چیدمان واکنش‌گرا برای موبایل

## مهم: داده و یکپارچه‌سازی

تمام آگهی‌ها، قیمت‌ها و موقعیت‌های این نمونه ساختگی هستند؛ نقشه شماتیک است و سرویس Neshan یا Divar فراخوانی نمی‌شود. این مخزن فعلاً فاقد کلید API، سرور، پایگاه‌داده و مجوزهای لازم برای دریافت/بازنشر محتوای آگهی‌هاست. بنابراین هیچ scraping خودکار از Zillow یا Divar انجام نشده است. پیش از اتصال به داده‌ی واقعی باید مجوز دسترسی و استفاده از داده بررسی شود، مسیر رسمی/API مجاز انتخاب شود و برای Neshan کلید API و سیاست نمایش/ذخیره‌سازی فراهم شود. فرم ثبت آگهی و ورود نیز در این نسخه فقط نمایشی هستند.
